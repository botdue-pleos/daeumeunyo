## 2026-11-10 · 0.1.0 첫 구현

### 왜
네 번째 출품작. 기획서 v0.1(발달장애 동승자 이동 예고)과 화면 시안 5장을 실제로 도는 앱으로 옮겼다.
2차 PT에서 구조를 직접 설명해야 하므로, 앞의 세 앱처럼 판정은 화면과 분리된 순수 Kotlin 엔진에 두었다.

### 무엇을
- `engine/RouteCards.kt`: 경로 → 3~5칸 카드. 같은 종류가 이어지면 한 칸, 넘치면 우선순위 낮은 칸(옆 길 → 큰 길)부터 뺀다. 남은 시간을 노래 곡 수로(`SongClock`, 한 곡 3.5분 기본)
- `engine/ChangeAnnouncer.kt`: 재탐색 전후 카드를 비교해 바뀐 칸·빠진 칸·늘어난 곡 수와 말할 문장. 목적지가 그대로면 그 말부터. 터널이 빠지면 바뀐 칸에 "터널은 이번엔 안 지나가요"
- `engine/TunnelCue.kt`: 남은 거리 ÷ 차속으로 1분 전(말·노래·내기순환), 30초 전(한 번 더), 통과 후 원래대로. 거의 서 있으면 시속 20km로 가정해 너무 이르게 말하지 않음. 늦게 안내받으면 30초 단계에서 노래도 같이 시작
- `engine/GuardianWatch.kt`: 달리는 중 뒷자리 벨트·문·창문(절반 이상)만, 같은 일은 1분에 한 번. 보호자 말("쉬자", "힘들어했어") 알아듣기, 쉼터 칸 넣기
- `engine/MomentLog.kt`: "힘들어했어"를 5분 안 가장 가까운 상황에 묶는다. `LeadPolicy`: 그 터널은 2분 전부터, 길 바뀜 2번 넘게 힘들면 꺾기 예고 30초 → 1분, 바꾼 때 전후 2주 비교
- `car/CarOutputs.kt`: 안드로이드 TTS, 터널 노래(MediaPlayer + 오디오 포커스 GAIN_TRANSIENT), 공조는 시연용
- `ui/`: 시안 그대로 출발 전·주행(터널)·길 바뀜·보호자 알림·도착·이동 노트(가로 2칸). 그림은 `Picto.kt`에 SVG 경로로 직접
- `tools/make_calm_song.py`: 기본 노래를 직접 합성 (저작권 걱정 없음)

### 확인
- `./gradlew testDebugUnitTest` 23개 통과
- 휴대폰 에뮬레이터(920x1414, density 240)에서 9개 장면 캡처 → `docs/screens/`
- 터널 1분 전 장면에서 `dumpsys audio`로 이 앱이 GAIN_TRANSIENT·USAGE_MEDIA 포커스를 잡은 것, 통과 후 놓은 것 확인. 충돌 없음
- 고친 것: 점선 테두리를 `drawBehind`로 그려 흰 배경에 덮였음 → `drawWithContent`로 내용 위에. 바뀐 칸이 지금 칸이면 겨자색이 아니라 보라 점선으로

## 2026-11-10 · 시연 영상

- 앞의 세 출품작과 같은 타이포그래피 형식: 공감 → 숫자 → 로고 → 실제 녹화 6장면 → 판정 엔진 → 마무리, 1920x1080 30fps 무음·자막
- 녹화 6개: 출발 전, 터널 1분·30초 전, 길 바뀜, 벨트 알림과 쉼터, 도착과 이동 노트, 가로 이동 노트(정지 화면). 에뮬레이터 920x1414(가로 1870x1414), density 240, 터치 표시
